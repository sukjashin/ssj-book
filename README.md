# ssj-book — 주제선언문 작성기

책을 쓰기 전에 **책 전체의 방향을 정하는 한 문장(주제선언문)** 을 쉽게 만들도록 돕는 도구입니다.
HTML 파일 하나로 되어 있어 설치 없이, 인터넷 없이도 작동합니다.

## 사용법
1. `index.html` 파일을 더블클릭하면 브라우저에서 열립니다.
2. 한 페이지를 위에서 아래로 내려가며 진행합니다. 상단 메뉴로 원하는 단계로 바로 이동할 수 있습니다.

| 단계 | 내용 |
|---|---|
| 01 개념 · 02 5요소 | 소재 → 주제 → 주제선언문, 독자·문제·관점·방법·변화 |
| 03 재료 찾기 | 6가지 질문에 답하기 (예시 불러오기 지원) |
| 04 한 문장 | 6가지 유형의 후보 문장 비교 → 골라서 다듬기, 길이·추상어 자동 점검 |
| 05 선언문 전문 | 현실 → 전환 → 약속 → 변화 4단 구조의 산문 초안 |
| 06 AI 편집자 | 주제선언문 · 전문 · 목차용 프롬프트 3종 복사 |
| 07 검증 | 7개 항목 0~10점 자가 평가 |
| 08 목차·기획서 | 부·꼭지 목차 틀, 장르별 집필 구조·분량·일정이 담긴 9항목 초고기획서 (마크다운 저장) |

## 참고
- 입력한 내용은 사용 중인 브라우저에만 자동 저장되며, 어디로도 전송되지 않습니다.
- 받침에 따라 조사(이/가, 을/를, 으로/로)가 자동으로 맞춰집니다.
