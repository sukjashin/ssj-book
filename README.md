# 주제선언문 작성기

책을 쓰기 전에 **책 전체의 방향을 정하는 한 문장(주제선언문)** 을 쉽게 만들도록 돕는 도구입니다.
HTML 파일 하나로 되어 있어 설치 없이, 인터넷 없이도 작동합니다.

## 사용법
1. `index.html` 파일을 더블클릭하면 브라우저에서 열립니다.
2. 왼쪽 메뉴의 7단계를 차례로 진행합니다. (키보드 ← / → 로 이동 가능)

| 단계 | 내용 |
|---|---|
| 1. 개념 이해 | 소재 → 주제 → 주제선언문의 차이 |
| 2. 핵심 요소 | 독자 · 문제 · 관점 · 방법 · 변화 |
| 3. 재료 찾기 | 6가지 질문에 답하기 (예시 불러오기 지원) |
| 4. 문장 작성 | 문제 해결형 · 관점 전환형 · 정의형 공식으로 초안 자동 조립 |
| 5. AI 활용 | 입력값이 반영된 AI용 프롬프트 복사 |
| 6. 검증하기 | 7개 항목 0~10점 자가 평가 |
| 7. 초고기획서 | 가제 · 목차 · 분량을 담은 기획서 작성, 복사 · 텍스트 저장 · 인쇄 |

## 참고
- 입력한 내용은 사용 중인 브라우저에만 자동 저장되며, 어디로도 전송되지 않습니다.
- 받침에 따라 조사(이/가, 을/를, 으로/로)가 자동으로 맞춰집니다.
